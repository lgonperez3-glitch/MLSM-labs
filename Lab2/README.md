# Lab 2 — Music Genre Classification with CNNs

El notebook principal es [`Lab2_CNN_Music_Genre.ipynb`](Lab2_CNN_Music_Genre.ipynb).

## Datos

Descarga `images_original` desde el enlace de datos del guion y colócala en `Lab2/Data/images_original/`, conservando una subcarpeta por género. Si la carpeta está en otra ubicación, cambia `DATA_DIR` en la sección 2 del notebook.

## Ejecución

Abre el notebook en Jupyter o Google Colab y ejecuta las celdas en orden. Se recomienda GPU para acelerar VGG16. El notebook compara tres configuraciones de CNN y una VGG16 preentrenada, y evalúa ambos modelos con el mismo conjunto de test.

La carpeta `Lab1` no se modifica en este trabajo.

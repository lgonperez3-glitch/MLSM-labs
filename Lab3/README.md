# Lab 3 — Autoencoder with MagnaTagATune

This folder contains the self-contained notebook for the Lab 3 assignment.

- `lab3_autoencoder_mtat.ipynb`: data preparation, convolutional autoencoder training, comparison experiments, validation metrics, audio reconstruction examples, and the report.

## Run

Open the notebook in Google Colab using the badge at the top and execute cells in order. A GPU runtime is recommended. The notebook downloads the three official MTAT MP3 archive parts from MIRG, joins and extracts them, then creates a clip-level train/validation split.

The training and validation segments are one second at 16 kHz. Both experiments use a 512-dimensional bottleneck and therefore keep the reference compression rate fixed at 31.25x.

**Note:** training metrics and conclusions are generated by executing the notebook. No numerical results are pre-filled or fabricated.
